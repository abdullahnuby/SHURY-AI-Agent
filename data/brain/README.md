# SHURY Brain Data

This directory stores **prior knowledge**, not fake runtime experience.

`brain.db` is generated by `/brain-bootstrap` or `/brain-ingest`.

Accepted user training records are JSONL/NDJSON/JSON/CSV with these useful fields:

- `goal` or `text`
- `domain`
- `capability`
- `interaction_shape`
- `required_tools`
- `tool_order`
- `constraints`
- `failure_modes`
- `success_invariants`

A training example teaches a *pattern or procedure*. It does **not** increment runtime
success counters and cannot auto-promote a Skill. Promotion still requires verified
runtime evidence.
