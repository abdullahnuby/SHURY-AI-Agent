## V22.5.0 — Layer 2 Semantic Understanding

- Added typed semantic parsing before planning: intent candidates, domains, entity mentions, grounded references/coreference, temporal expressions, constraints, slots, speech acts, actionability and fresh-data signals.
- Added deterministic paraphrase routing with selective model-backed semantic fallback; model outputs are schema-constrained and safety-merged into grounded local context.
- Added multilingual reference grounding for same-utterance, forward demonstratives and bounded previous-turn context; unresolved references now produce clarification instead of guesses.
- Added temporal normalization for relative dates/times using the application timezone (`Africa/Cairo`) and semantic deduplication.
- Added pragmatic speech-act handling for questions, commands, polite requests, statements and corrections.
- Added semantic correction grounding so follow-ups such as “No, I mean Cairo” map to the previously established fact/preference key only when evidence exists in the same session.
- Added semantic acceptance benchmark with 50 cases across Arabic, English, mixed identifiers, memory, web, scientific research, GitHub, data, development and RAG.
- Added `/semantic <text>` and `/semantic-benchmark` CLI commands.
- Updated deterministic decision gating to use high-confidence Layer 2 interpretation when the legacy classifier is ambiguous, without bypassing runtime policy/approval/verification.
- Full regression suite passes **270/270**; semantic benchmark passes **50/50**.
