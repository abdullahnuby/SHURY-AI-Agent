# V22.2 — Full Memory Subsystem

## Added

- Layered working, episodic, semantic, procedural, temporal and graph memory.
- Versioned memory items with supersession and history.
- Hybrid retrieval with lexical, character, entity, recency, importance, confidence and MMR-style diversity signals.
- Scope-aware working memory and cross-session persistent memory.
- Explicit observation pipeline: episode -> conservative candidate extraction -> promotion.
- Repeated-success procedural memory promotion from verified tool sequences.
- Temporal validity with `valid_at`, `invalid_at`, and `expires_at` enforced on read paths.
- Session summaries, memory health diagnostics, portable export and restore.
- Privacy gate against credential/secret persistence and episodic redaction.
- Offline memory benchmark covering recall, updates, episodes, procedures, expiry, forgetting, provenance, health and restore.

## Fixed

- Natural-language name recall routing (`do you remember my name?`).
- Generic memory search no longer falls into the profile route.
- User provenance survives automatic confirmations.
- Future/invalid memories are excluded from current fact/profile retrieval.
- Legacy malformed name placeholders (`?`) are archived during migration.
- Graph relations honor temporal validity.
