# V22.4.1 — Layer 1 Cognitive Core

Implemented the first planned layer of the Real Agent roadmap.

## Flow
User goal
→ cognitive analysis
→ deterministic baseline candidate
→ governed ReAct execution
→ observation
→ cognitive reflection
→ next decision / replan

## Principles
- The model proposes and critiques; the runtime remains the authority.
- Cognitive output is structured JSON, not free-form JSON scraping when Anthropic is used.
- Memory/tool/file/web content remains untrusted data.
- Reflection stores concise decision summaries only, not private chain-of-thought.
- Runtime policy, approval, verification, state transitions and side effects are unchanged.
- `/agent <goal>` uses the Cognitive Agent.
- `/react <goal>` keeps raw ReAct available.
