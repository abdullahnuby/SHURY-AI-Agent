# V22.9.1 Verification

## Issue
Windows Python 3.14 may not expose an IANA timezone database, causing `ZoneInfo("Africa/Cairo")` to raise `ZoneInfoNotFoundError`.

## Fix
- `app/core/time.py` resolves IANA zones when available.
- Cairo has a deterministic fallback for supported current Egyptian DST rules when tzdata is absent.
- `requirements.txt` declares `tzdata>=2026.4`.
- Semantic temporal parsing now uses the resolver and cannot crash merely because tzdata is absent.

## Verification
- Missing-tzdata regression tests: PASS
- Full regression suite: see release run
- CLI `py -m app.main` startup: PASS
