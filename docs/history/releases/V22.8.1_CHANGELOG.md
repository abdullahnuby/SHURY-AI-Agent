# V22.8.1 — Layer 5 Self-Improvement Hardening

- Added dedicated learning subsystem for durable experiences, contrastive lessons, reflection-derived lessons, counterfactual replay, candidate skill generation, evidence-gated promotion, and rollback.
- Added learned guidance injection into ReAct as explicitly untrusted advisory context.
- Added environment-configurable learning and skill databases (`AGENT_LEARNING_DB`, `AGENT_SKILLS_DB`) for isolated testing and deployments.
- Added `/learning-status`, `/learning <goal>`, `/evolve <skill-key>`, `/rollback <skill-key>`, and `/self-improvement-benchmark`.
- Candidate skills require repeated verified evidence and positive/non-regressive replay before activation; trust/policy/approval/verification remain authoritative.

- Real-user hardening: failure→success contrastive learning, legacy reflection cleanup, task-signature credential redaction, CLI dispatcher coverage, workflow dependency preservation, and generalized learned triggers.

- V22.8.1 hardening: real-user failure→success acceptance, CLI dispatcher coverage, legacy reflection reconciliation, credential-safe task signatures, generalized learned triggers, preserved workflow dependencies, and an expanded self-improvement benchmark.
