## Provenance policy

Every record is marked as `source=synthetic_seed` and carries `not_execution_evidence=true` and `not_user_memory=true`.
Seed records cannot directly create user memory, execution evidence, citations, or Skill promotion evidence.

## Runtime integration

The Cognitive Core receives up to four relevant seed examples as non-authoritative priors.
The seed store exposes read-only `get`, `search`, `context`, and `stats` operations.
